polis-serverless

用一個 Cloudflare Worker + Durable Object 走完一輪 Polis 式意見調查——不用自架伺服器、不用資料庫服務。

一輪的流程：發起討論（設定題目與種子陳述）→ 參與者對陳述投「同意／不同意／略過」並提出新陳述 → 系統以 PCA + k-means 畫出意見地圖與分群 → 產出各群代表性陳述與跨群共識報告。

它怎麼運作

每場討論是一個 Durable Object，投票與陳述存在它自帶的 SQLite；意見分群（平均插補 → PCA → k-means、silhouette 選 2–5 群）與代表性／共識統計（含 pseudocount 的比例檢定）都在 Worker 內即時計算——整套只需要 GitHub（原始碼）與 Cloudflare（執行），沒有伺服器要維護。演算法依 Polis 公開文獻重新實作，非官方 pol.is，亦未使用其程式碼。

原始碼：github.com/mashbean/polis-serverless（MIT）。與 The Computational Democracy Project 的 pol.is 無隸屬關係。參與是匿名的：系統只在你的瀏覽器存一個隨機代號，不蒐集姓名或 email。
