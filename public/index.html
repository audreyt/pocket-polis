polis-serverless

免自架伺服器的完整一輪 Polis 式意見調查：大家提陳述、對彼此的陳述投「同意／不同意／略過」，系統即時畫出意見地圖、找出各群的代表性立場與跨群共識。一個 Cloudflare Worker 就是整套系統。

Demo：【模擬】國防軍購特別預算公投

113 位虛構立法委員（化名取自台灣物種與地景，非真實個人）依第 11 屆立法院政黨席次結構——綠 51、藍 52、白 8、無黨籍 2——由程式模擬投票。地圖分裂成 62:51 兩群、沿著「兩岸對話 vs 軍購嚇阻」「特別預算舉債」的斷層線對立，卻在透明、監督、全民防衛韌性等五句陳述上出現 67–83% 的跨群共識。

對話開放中：你的每一票都會即時改變地圖。模擬方法與快照見 案例說明。

加入投票 看意見地圖與共識

一輪怎麼走

  1. 發起——設定題目與 5–15 句種子陳述，立刻拿到參與、結果、管理三條連結。
  2. 參與——參與者匿名投票（一句一句來），也能提出自己的陳述；票少的新陳述會優先曝光。
  3. 收斂——投票矩陣經 PCA + k-means 分群（silhouette 自動選 2–5 群），產出各群代表性陳述（90% 顯著性檢定）、跨群共識清單、匿名化 CSV。

演算法忠實度：用官方 Polis 開放資料（CC BY 4.0）驗證，vTaiwan UberX、Brexit、Bowling Green 三個資料集群數全對、與官方分群的 Adjusted Rand Index 0.78–0.86；22.5 萬票的資料集 236ms 算完。細節見驗證報告。

把它變成你的

這裡是展示站。正式使用請部署到你自己的 Cloudflare 帳號——資料存在你自己的 Durable Object SQLite，免費方案就能跑，沒有伺服器要維護。三條路：

A · 讓你的 AI agent 來

把下面這段貼給 Claude Code、Cursor 等 coding agent。你只需要在瀏覽器完成 wrangler login 的 Cloudflare 登入，其他（安裝、檢查、部署、建立第一場討論）都交給它。

請照 https://github.com/mashbean/polis-serverless/blob/main/AGENT.md 的說明，把 polis-serverless 部署到我的 Cloudflare 帳號（wrangler login 那一步我自己完成），部署完成後用 API 幫我建立第一場討論。
看 AGENT.md

Claude Code 使用者也可以先安裝 skill：npx --yes github:mashbean/polis-serverless install-skill

B · 一鍵部署

登入 Cloudflare 後按下按鈕，Cloudflare 會 fork 這個 repo 到你的 GitHub 並自動建置部署。

C · 手動六行

git clone https://github.com/mashbean/polis-serverless.git
cd polis-serverless
npm install
npx wrangler login
npm run check
npm run deploy

要綁自訂網域：把 wrangler.jsonc 的 env.production.routes 改成你的網域後 npm run deploy:production。

資料與隱私

參與是匿名的：瀏覽器只存一個隨機代號避免重複計票，不蒐集姓名、email，無 cookie、無追蹤器。管理金鑰走 URL fragment、伺服器只存 SHA-256。匯出的 CSV 以 p1、p2⋯匿名化。誠實聲明：這種輕量身分擋不住刻意灌票，適合信任圈內的社群、課堂與工作坊；高對抗性的公共諮詢請用官方 pol.is。
